    -   <details open><summary style="font-size:20px;color:#C71585">Per se</summary>

        > Literally translated from Latin, **per se** means **"by itself"** or **"in and of itself"**. In everyday conversation, we use it to distinguish between something in its most basic, isolated form versus that thing in a specific context or connection.

        > You use *per se* when you want to say that something isn't necessarily true or bad on its own, but there might be other factors at play.

        -    **The Job:** "It’s not the job **per se** that I hate; it’s the long commute."
            -   (The work itself is fine, but the travel is the problem.)*
        -    **The Song:** "She isn't a bad singer **per se**, but this song is definitely out of her range."
            -   (She has talent in a general sense, but this specific performance is lacking.)*
        -    **The Food:** "The dish wasn't spicy **per se**, it just had a lot of flavorful herbs."
            -   (It didn't have heat, but it had complexity.)*

        | Feature      | Incorrect                | Correct                           |
        | ------------ | ------------------------ | --------------------------------- |
        | **Spelling** | per say                  | **per se**                        |
        | **Origin**   | Phonetic mistake         | Latin (*per* = by, *se* = itself) |
        | **Usage**    | Common in informal texts | Standard English / Professional   |

        > **Pro Tip:** If you aren't sure if it fits, try replacing "per se" with the phrase **"in and of itself."** If the sentence still makes sense, you're using it correctly!

    -   <details open><summary style="font-size:20px;color:#C71585">Patch</summary>

        > In software engineering, a patch is a piece of software designed to update, fix, or improve a computer program or its supporting data.

        1. **Noun (*a fix, update, or code change*)**

            * **Hotfix / Critical Fix**: We found a memory leak in production after yesterday's deployment, so we need to roll out a emergency **patch** within the hour.


            * **Release Versioning (SemVer):**
            > *"This update only fixes a minor layout bug, so bump the version as a **patch** release from `2.4.1` to `2.4.2`."*


            * **Git Commit / Diff:**
            > *"Can you email or send me the unified **patch** file so I can review the changes offline?"*



        2. **Verb (*to fix, update, or modify code/systems*)**: 

            * **Applying Security / Dependency Updates:**
            > *"We need to **patch** our dependencies this sprint to resolve those CVE vulnerabilities flagged by the security scanner."*


            * **Fixing Buggy Code:**
            > *"I managed to **patch** that edge-case bug in the payment gateway logic, but we still need proper unit tests for it."*


            * **Temporary / Workaround Fix:**
            > *"Let's **patch** the API endpoint for now so users stop getting 500 errors, and we can refactor the underlying database query next sprint."*



        3. **Verb in HTTP Method Context (`PATCH` request)**: 

            * **Partial Update of Resources:**
            > *"Don't use `PUT` here since that replaces the entire user profile object—use a **`PATCH`** request so we only update the user's email address."*



        4. **Adjective (*describing a fix, version, or branch*)**: 

            * **Patch Release / Patch Version:**
            > *"Our team is focusing on the upcoming minor release, but team B is cutting a **patch** release for the v1.2 legacy branch."*


            * **Patch File:**
            > *"Apply the **patch** file using `git apply my-changes.patch` to see if it fixes the build error on your local machine."*



        5. **Summary Checklist for Quick Reference**: 

            | Part of Speech | Meaning in Software Engineering                     | Example Phrase                                        |
            | :------------- | :-------------------------------------------------- | :---------------------------------------------------- |
            | **Noun**       | A piece of software designed to update/fix code     | *"Deploy the **patch** to production."*               |
            | **Verb**       | To apply a fix or update a dependency               | *"We need to **patch** OpenSSL."*                     |
            | **HTTP Verb**  | An HTTP request method for partial resource updates | *"Send a **PATCH** request with the updated fields."* |
            | **Adjective**  | Modifying a release, version, or file type          | *"Check the **patch** notes before upgrading."*       |
